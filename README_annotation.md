# 特許SAO 教師データ作成ツール

## 使い方

1. `app_annotation.py` と `requirements_annotation.txt` を同じフォルダに置く
2. 必要パッケージをインストール
3. `streamlit run app_annotation.py`
4. 請求項を貼り付ける
5. GiNZAでトークン化
6. 各トークンを `B-COMP / I-COMP / O` に分類
7. 構成要素間の関係を `source → relation → target` で登録
8. `components.csv` と `relations.csv` を保存
9. 20～100件程度を作ったら、次に機械学習モデルの学習コードを作る

## アノテーション方針

- `B-COMP`: 構成要素の開始
- `I-COMP`: 同じ構成要素の続き
- `O`: 構成要素ではない
- 「前記」「少なくとも」「主面」「一部」などは原則 `O`
- 「有する」「含む」「配置」「位置決めされる」などは関係として登録
- `source → relation → target` の向きを原文の意味に合わせる

- インテリジェントパワーモジュール → 有する → 放熱装置
- インテリジェントパワーモジュール → 有する → 取り付けフレーム

- パワー半導体モジュール → 含む → 負側電源入力端子
- パワー半導体モジュール → 含む → 出力端子
- 取り付けフレーム → 有する → 開口部
- パワー半導体モジュール → 位置決めされる → 取り付けフレーム
